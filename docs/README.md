# ติดมันส์ สตูดิโอ

Repository สำหรับ source code, การติดตั้งเครื่องใหม่ และแจก Patch อัตโนมัติ
โดยไม่รวม Account, Cookie, Context หรือไฟล์งานผู้ใช้

## ติดตั้งหรือกู้คืนบนเครื่องใหม่

```bat
git clone https://github.com/tidmunzsocial-lab/tidmunz-studio.git SnapGen
cd SnapGen
setup_and_run.bat
```

อ่านรายละเอียดเพิ่มเติมที่ `RECOVERY_FROM_GITHUB.md`
